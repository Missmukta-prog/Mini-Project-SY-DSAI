# Group C Mini Projects
Two browser-based mini projects using HTML, CSS, and JavaScript.

## Run
1. Extract the ZIP.
2. Open the relevant project folder.
3. Double-click `index.html` or open it in a browser.
4. No installation or internet connection is required.

## P1 — Online Food Processing System
- Queue/FIFO order handling.
- Add food orders, update the first order through Received → Preparing → Ready → Completed.
- Completed order history and clear-history action.

## P2 — Hospital Emergency Management System
- Priority queue ordering: Emergency → Urgent → Normal.
- FIFO order is maintained among patients of the same priority.
- Patient records are maintained in a manually implemented singly linked list.
- Search records and complete treatment for the first patient.

## Important notes
- These are educational prototypes. Data is held in JavaScript memory and resets when the page is refreshed.
- P2 is not a clinical triage tool and must not be used for real patient care.
- Before submission, test all cases, capture screenshots from your own browser, and add your names, roll numbers, class, teacher, and institution details to the reports.
